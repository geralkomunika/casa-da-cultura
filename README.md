# Casa da Cultura César Oliveira

Homepage responsiva de demonstração para a Casa da Cultura César Oliveira, feita em HTML, CSS e JavaScript sem dependências de compilação.

## Ver o site
Abra [index.html](./index.html) no repositório ou ative GitHub Pages para publicar o site.

## Publicar com GitHub Pages
1. Abra **Settings** neste repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)), depois carregue em **Save**.
5. Aguarde a publicação. O endereço deverá ser `https://geralkomunika.github.io/casa-da-cultura/`.

## Antes de publicar
- Os eventos apresentados são exemplos ilustrativos, não uma agenda oficial.
- Confirme e substitua textos, eventos, contactos, morada e horários pelos dados oficiais.
- As imagens são carregadas a partir do Unsplash e podem ser substituídas por fotografias autorizadas da instituição.
- Este projeto é uma proposta visual independente; não altera automaticamente o site Wix existente.
